# Рисуем вместе (draw-with-friends)

Веб-приложение для совместного рисования с друзьями в реальном времени.

- **Вход через Google** (OAuth 2.0), профиль с никнеймом и аватаром: фото из Google, своя картинка или значок на цветном фоне.
- **5 полотен** на старте, трёх типов:
  - **Свободное**: все рисуют одновременно, штрихи видны сразу.
  - **По раундам**: игроки присоединяются, получают общую тему и рисуют по очереди, у каждого ограниченный по времени ход (2 круга).
  - **С помощником**: пошаговые уроки в духе ArtLoop. На полотне появляется пунктирный контур текущего шага, все вместе его обводят и листают шаги.
- Кисть, ластик, палитра, толщина, отмена своего штриха, очистка, сохранение PNG.

## Стек

Node.js 22, Express, Socket.IO, PostgreSQL (или память процесса, если `DATABASE_URL` не задан). Фронтенд без сборки: обычные ES-модули в `public/`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | OAuth-клиент Google (тип «Web application»). Redirect URI: `https://<домен>/auth/google/callback` |
| `SESSION_SECRET` | Ключ подписи cookie сессии |
| `DATABASE_URL` | Строка подключения PostgreSQL; без неё данные живут в памяти |
| `PUBLIC_URL` | Необязательно: внешний адрес, если прокси не передаёт хост |
| `DEV_LOGIN=true` | Только для локальной разработки: вход по имени без Google |
| `PORT` | Порт (по умолчанию 8080) |

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:8080, тестовый вход без Google
npm test
```

## Деплой

Сервис живёт на [mctl](https://mctl.ai) в рабочем пространстве `drawing`. Пуш в `main` запускает CI (`.github/workflows/ci.yml`): тесты, новый тег SemVer и деплой через mctl API. Для деплоя из CI нужен секрет репозитория `MCTL_GITHUB_TOKEN` (classic PAT со scope `read:user`); без него шаг деплоя пропускается.
